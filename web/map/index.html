3 · 출발선 설정

정확도 10m 이내의 최신 GPS를 기다립니다.현재 위치 또는 지도 두 점으로 선을 만드세요.

출발선 없음

각도 슬라이더로 회전하고 지도 위 중심 손잡이를 끌어 위치를 조정하세요. 저장 전에는 미리보기입니다. 노란 화살표가 인정되는 통과 방향입니다.저장 → 랩 측정 시작 → 선 뒤쪽으로 최소 5m(위치 오차보다 멀리) 이동 → 화살표 방향으로 통과하세요. 첫 통과에서 타이머가 시작되고, 다음 정상 통과에서 한 랩을 완료합니다.
