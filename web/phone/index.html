화면 잠금·다른 앱 사용 중에도 위치를 보내려면 아래 아이폰 앱 연결을 사용하세요. 위치는 현재 대시보드의 지도·기록으로 전달됩니다.

아이폰 · 백그라운드 GPS

  1. Traccar Client 설치 ↗ 후 앱을 엽니다. Device identifier는 앱의 기본값을 유지하세요.
  2. 앱의 Server URL에 아래 주소를 붙여넣습니다. 주소를 설정한 뒤 서비스를 시작하세요.
  1. 아이폰 설정 → 개인정보 보호 및 보안 → 위치 서비스 → Traccar Client에서 항상 허용 · 정확한 위치 켬으로 설정합니다. 처음에는 앱에서 위치 권한 요청을 허용하세요.
  2. 앱에서 Location accuracy: Highest, Interval: 1초, Stop detection: 끔으로 설정합니다. 버전에 따라 메뉴 이름이 다를 수 있습니다.
  3. 앱의 서비스를 켠 뒤 화면을 잠급니다. 앱 전환 화면에서 위로 밀어 강제 종료하지 마세요. 주행 측정 중에는 저전력 모드를 끄세요.
1초는 요청 간격이며 아이폰의 실제 위치 제공 주기를 보장하지 않습니다. 통신 후 늦게 도착한 위치는 현재 위치나 유효한 랩타임으로 처리하지 않습니다. 웹 GPS와 앱 GPS는 동시에 켜지 마세요. 
앱 연결 확인 중
화면을 잠근 상태에서 다른 기기의 이 페이지로 수신 건수가 증가하는지 확인하세요. 저장은 대시보드의 측정 기록 상태를 따릅니다. 종료할 때는 Traccar Client에서 서비스를 끄세요.
