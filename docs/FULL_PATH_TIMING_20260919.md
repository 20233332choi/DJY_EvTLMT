# 전방 센서 취득 → 후방 제어 틱 계측 준비

상태 갱신(2026-09-20): 후방에 전체 경로 계측, 조향 영점 9175, ESP 전달용 `ts=` 확장을 적용하고 Flash 검증했다. ESP의 `board_timing` 무선 전달 기능은 빌드·호스트 테스트 완료, 아직 미적용이다. 최신 후방 USB 비동기 출력 수정도 빌드 완료 상태이며 아직 미적용이다. 현재 USB 장치 및 새 무선 데이터가 없어 **전체 경로 실측 결과는 없다**. 사용자는 USB 수집이 아니라 ESP 인터넷 경로로 검증하도록 명시했다.

## 연결 조건

전방 USB를 PC에서 분리해도 전방 보드와 센서의 전원, 전방↔후방 CAN H/L 및 공통 기준 전위는 유지해야 한다. 후방 STM의 ST-Link USB를 PC에 연결해야 Flash 및 진단 수집이 가능하다. 이 시험에서 ESP는 필수가 아니다. 기존 사용자 확인 조건은 차량 정지 및 구동모터 전원 OFF였다.

## 새 계측 항목

기존 전방 펌웨어는 취득 중간 시각과 전체 취득 span을 보낸다. 중간 시각에서 `span/2`를 빼 취득 시작을 복원한 다음, 후방 시계로 별도 변환한다. 전방의 마이크로초를 후방 결과에 직접 더하지 않으므로 발진기 skew도 반영한다.

| 출력 metric | 의미 |
|---|---|
| front_acq_rx | 전방 SAS 읽기 시작 → 후방에서 0x100/0x101 센서 쌍 수신 완료 |
| front_acq_ctrl | 전방 SAS 읽기 시작 → 해당 입력이 있는 후방 제어 ISR 시작 |
| front_rx_ctrl | 후방 센서 쌍 수신 완료 → 후방 제어 ISR 시작 |
| front_link / front_age | 기존 취득 **중간** 시각 기준 수신/제어 입력 나이 |

유효한 시계 매핑과 신선한 timestamped 센서 쌍이 있는 제어 틱만 집계한다. 누적 통계는 100 Hz 제어 틱에 사용 가능한 최신 입력을 기준으로 하며, 개별 CAN 프레임 전체에 대해 1회씩 집계한 값은 아니다. P95는 기존 히스토그램 버킷의 상한이다. 취득/변환 지연, 완전한 두 프레임 수신까지의 통신 지연, 제어 틱 대기를 포함하지만 센서 내부 물리 응답, 다음 전방 취득을 기다리는 100 Hz 폴링 대기, 후방 필터 위상 지연, 토크 출력/구동계 반응은 포함하지 않는다.

후방 CAN RX보다 TIM6 제어 IRQ가 우선순위가 높아, 기존 센서 값과 시각 구조체를 갱신하는 중간에 제어 IRQ가 실행될 수 있었다. 새 v2 센서 쌍의 값·스위치·시각·freshness를 짧은 인터럽트 마스킹 구간에서 함께 갱신하도록 보완했다. PID 계산이나 게인은 변경하지 않았다.
