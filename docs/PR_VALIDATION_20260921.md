## USB·DB 추가 검증

- 실제 ESP formatter의 48셀·긴 진단값을 자릿수까지 유지한 USB 프레임으로 3 Mbps 선로·4096바이트 UART 버퍼·PC ACK 지연 10 ms를 모의했습니다. 200 표본/s로 생성한 2,000개를 누락 없이 전달·저장했습니다. 실측 선로 시험은 아닙니다.
- 부분 쓰기, CRC 오류, 과대/분할 수신, ACK 유실, USB 스키마 재사용을 검사했습니다. PC serial_loop에서 CRC 오류와 DB COMMIT 실패에 ACK하지 않고 재전송 후 각 표본을 한 번 기록하는 것도 확인했습니다.
- USB·UDP·HTTPS 중복 및 지연 수신 1,000개가 DB와 피트/BMS 그래프에 각각 한 번만 남고, 과거 표본이 최신 차량 값을 되돌리지 않는지 검사했습니다.
- DB 삽입 실패와 묶음 마지막 UPDATE 실패 모두 그래프에 미반영되고 오류 상태가 나타납니다. 재시도 후 DB/두 그래프 각각 2개이며 4개로 중복되지 않습니다. 표시용 UDP 실패도 완료된 저장을 취소하지 않습니다.
- 최종 Python 검사에는 `/tmp/ev-binary-build-tools`의 pyserial을 사용했습니다. JavaScript 문법과 수정분 공백 검사도 통과했습니다.
