# BMS 대시보드 복구 — 2026-09-17

- ESP JSON 버퍼를 3072 → 4096바이트로 확대. 기존 버퍼는 BMS 필드를 붙인 뒤 전송을 중단했다.
- BMS JSON 추가 시 기존 닫는 괄호를 덮어쓴 1바이트를 전송 길이에서 제외. UDP에 붙던 NUL 제거.
- CAN 수신의 잘못된 `0x1ffff` 주소 마스크 제거. ID 전체 검증은 유지한다. 기존 마스크는 홀수 데이터 ID(0x91/93/95/97)를 버려 셀 전압 및 MOS 상태가 누락됐다.
- PC를 ESP와 같은 HyengmInPhone에 연결. 로컬 `config.h`의 `EV_PIT_HOST`를 현재 PC 주소 `172.20.10.7`로 수정.
- COM8 ESP32-S3에 `platformio-modern.ini`로 빌드/업로드 완료, 플래시 해시 검증 성공.

## 검증

- 실제 ESP 포맷터/수신기를 컴파일하는 `python tests/test_esp_bms_packet.py`: 2개 통과.
- 기존 게이트웨이 33개, DALY 디코더 3개 테스트 통과. 합계 38개.
- 실제 WIFI_UDP 수신 패킷 1372 → 1393 증가, 약 3.5~4 Hz, BMS 수신 지연 47~172ms 표본 확인.
- 팩 58.1V, SOC 100%, 14셀 4.149~4.154V, 충전 MOS OFF / 방전 MOS ON.
- 브라우저 `/battery`에서 BMS LIVE 및 셀 14개 표시 확인.
- 실제 BMS 알람 원문 `1200000000000000` 수신. 경고 원인 해석/해제 및 차량 구동 검증은 수행하지 않음.

PC 주소는 고정 예약한 것이 아니다. 재연결 후 PC IP가 바뀌면 ESP 전송 목적지도 맞춰야 한다.
